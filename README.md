# ФінПро для дітей

Telegram-бот, який автоматично готує українськомовні пости про гроші,
технології та цифрову безпеку для підлітків. Контент генерує Gemini,
публікації планує APScheduler, а стан і черга модерації зберігаються в
Upstash Redis.

## Основні рубрики

- `#ТехНовини`, `#ШІ_Лайфхак`, `#ВідеоТижня`
- `#ГеймЕкономіка` — гроші та психологія покупок у відеоіграх
- `#СкількиКоштує` — реальні бюджети підліткових цілей
- `#ПершіГроші` — безпечні й легальні перші підробітки
- `#ГрошіВГолові` — психологія покупок і фінансових рішень
- `#СтартапТижня` — реальний продукт, бізнес-модель і ризики
- `#КриптоБезХайпу` — механіки доходу, технології та ризики крипти
- `#ПідпискаПастка` — автосписання, комісії й маркетингові пастки
- `#МіфПроГроші`, `#ФінТруКрайм`, `#ФінКвіз`
- `#ПрофесіїМайбутнього`, `#КіберБезпека`
- `#ТренажерМозку` — щодня, у стилі шоу «Клуб 1%»: на картинці велика
  зона задачі й бейдж «лише N%», у підписі коротке питання (~30 секунд).
  Типи без Gemini: піраміда чисел, дзеркало літер, прихована послідовність
  (місяці/дні/числа злиті докупи), закономірності, ребуси, зайве слово,
  анаграми, шифр, детективні задачі з солвером (алібі, хто бреше, порядок).
  Тип `clever` — кмітливі задачі від **Gemini** (відповідь лише з умови,
  без знань фактів); якщо модель не відповіла, слот бере інший тип.
  Публікується як опитування; розв'язок і статистика — наступного дня.
  Складність (1–5 → 90%…5%) рухається сама за точністю відповідей каналу;
  кожна задача запам'ятовується в Redis на `BRAIN_SEEN_TTL_DAYS`.
  Логічні задачі проходять через солвер: генератор перебирає всі варіанти й
  віддає задачу лише тоді, коли розв'язок рівно один. Умова з показаннями
  йде в підпис до картинки, а в саме опитування — коротке `poll_question`,
  бо в Telegram питання опитування обмежене 300 символами. З рівня 3 додається
  час на дорогу до місця події, тож просто «хто був відсутній» уже не працює
- `#ВгадайКраїну` / `#КраїнаВДеталях` — денний слот у понеділок, режими
  чергуються через тиждень (`ROTATIONS`). «Вгадай» — прапор і опитування,
  **без Gemini**; розв'язок із фактами й статистикою виходить наступного дня.
  У підписі 4–8 підказок (частина світу, острівність або відсутність виходу до
  моря, найбільші сусіди, моря, населення й площа в порівнянні з Україною, мови,
  валюта, бік руху), щоб країну можна було вивести, а не лише впізнати прапор.
  Факти, які містять корінь назви («японська мова», «кубинський песо»,
  «Японське море»), відкидаються — інакше відповідь у першому ж рядку. Якщо
  підказок менше чотирьох, країна пропускається: вгадувати навмання нецікаво.
  «Деталі» — цифри з Wikidata плюс абзац української Вікіпедії, Gemini лише
  переказує їх і не має права додавати свої факти.
  Дані: Wikidata (українські назви країн уже в комплекті) і FlagCDN — обидва
  без ключів. REST Countries тут не використовуємо: з 2026-го старі версії
  вимкнені, а v5 потребує авторизації. Довідник кешується на
  `COUNTRY_CACHE_TTL_DAYS`, бо SPARQL-запит триває десятки секунд
- `#НоваБанкнота` — свіжі/ювілейні випуски; джерела NewsAPI + Google News RSS + [bonistika.net](https://www.bonistika.net/) (RU→UA); перевірка раз на ~7 днів, дедуп
- `#ВідеоТижня` — 1 сканування Gemini на день; кілька гідних відео розкидаються по наступних днях з черги.
  Пошук іде за релевантністю, тривалість фільтрується вручну
  (`VIDEO_MIN_DURATION_SEC`..`VIDEO_MAX_DURATION_SEC`): параметр YouTube
  `videoDuration=short` означає «до 4 хв» і викидав усі демо й розбори,
  залишаючи Shorts

За замовчуванням автопілот вимкнений: бот надсилає новий матеріал
модератору, а публікація відбувається лише після натискання кнопки.

Плани щодо нових рубрик — у [PLAN.md](PLAN.md).

### Розклад, ротація і резервна рубрика

`SCHEDULE` у `config.py` задає слоти дня. Ключ слота може бути не рубрикою, а
**ротацією** з `ROTATIONS` — тоді рубрика вибирається по колу, а лічильник
живе в Redis, тому перезапуск бота не збиває чергу. Так дві близькі теми
діляться одним слотом і кількість постів на день не росте.

Якщо генератор нічого не знайшов (немає свіжих даних, вигоріла квота), слот
закриває резервна рубрика з `RUBRIC_FALLBACK` — вона має бути безкоштовною.
Фолбек викликається один раз і сам себе не рекурсує; порожнє значення означає
«просто пропустити слот».

`/test <rubric>` завжди звертається до конкретної рубрики й ротацію обходить.

## Локальний запуск

1. Встановіть Python 3.11.
2. Створіть віртуальне середовище та встановіть залежності:

   ```bash
   python -m venv .venv
   python -m pip install -r requirements.txt
   ```

3. Скопіюйте `env.example` у `.env` і задайте секрети.
4. Запустіть:

   ```bash
   python main.py
   ```

Health endpoint працює на `http://localhost:${PORT:-10000}/`.

### Gemini fallback

Моделі задаються через `GEMINI_MODELS` у порядку пріоритету. Код
автоматично ставить **flash** першими (`gemini-2.5-flash`, `gemini-2.0-flash`),
а Pro/preview — в кінець (щоб не витрачати квоту на 429). Рекомендовано:

1. `gemini-2.5-flash`
2. `gemini-2.0-flash`

При timeout, вичерпаній квоті (RPM), недоступній моделі (`403`)
або невалідному JSON бот чекає Retry-After (до 3 хв), тримає паузу між
запитами і переходить до наступної моделі. Розклад розносить рубрики одного
слоту на ~2.5 хв і при 429 повторює генерацію до 2 разів.
Денний ліміт (`RPD`) не маскується безкінечними ретраями.
Помилки невірного API-ключа (`401` / `API_KEY_INVALID`) не маскуються
fallback-моделями.

### Тон постів

Промпт кожної рубрики збирається в `build_base_prompt()` (`generators/gemini.py`)
поверх редакційного брифу з `config.py`:

- `EDITORIAL_TEAM_BRIEF` — модель працює як редакція соцмереж (стратегія,
  копірайтинг, креатив, спільнота), а не як чат-бот
- `POST_HOOK_STYLES` / `POST_ENDING_STYLES` — для кожного посту випадково
  обирається тип зачіпки й фіналу, щоб пости не звучали за одним шаблоном
- `BANNED_AI_PHRASES` — штампи («що це означає для тебе» тощо) заборонені в
  промпті; якщо модель усе одно їх вставила, прев'ю на модерації показує
  рядок `⚠️ Штампи: …`, а в логах з'являється warning

Emoji-ярлики у ФОРМАТі рубрик — орієнтир, а не обов'язковий шаблон: модель
може перефразувати їх живою мовою.

## Запуск у Docker

```bash
docker build -t finpro-bot .
docker run --env-file .env -p 10000:10000 finpro-bot
```

Контейнер містить DejaVu Fonts для українського тексту на зображеннях,
працює від непривілейованого користувача та має вбудований healthcheck.

## Northflank

1. Підключіть GitHub-репозиторій у Northflank.
2. Створіть **Combined Service** з типом build `Dockerfile`.
3. Вкажіть порт `10000`, протокол HTTP та health check path `/`.
4. Додайте всі змінні з `env.example` як secrets/configuration.
5. Залиште команду запуску з Dockerfile: `python main.py`.
6. Оберіть одну постійно запущену репліку.

Не запускайте дві репліки одночасно: кожна створить власний scheduler і
може опублікувати один пост двічі. Upstash лишається зовнішнім сховищем,
тому окремий Redis add-on у Northflank не потрібен.

## Команди модератора

- `/autopilot on|off`
- `/status`
- `/pause`
- `/resume`
- `/test crypto` — згенерувати одну рубрику лише в чат модератора
- `/test_all` — послідовно перевірити всі рубрики без публікації в канал
- `/help`
